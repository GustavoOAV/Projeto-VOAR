# 🚀 VOAR - Sistema de Comentários

Sistema de comentários moderno e responsivo desenvolvido para o site VOAR, permitindo interação dos usuários através de comentários e curtidas.

## ✨ Funcionalidades Principais

- **💬 Comentários em tempo real** - Sistema dinâmico e instantâneo
- **❤️ Curtidas inteligentes** - Controle por usuário único sem necessidade de login
- **🗑️ Exclusão segura** - Autores podem apagar seus próprios comentários
- **📱 Design responsivo** - Experiência perfeita em todos os dispositivos
- **🔐 Código único** - Sistema de segurança para controle de exclusão

## 🛠️ Tecnologias Utilizadas

- **React 18** - Framework frontend com hooks modernos
- **Firebase Firestore** - Banco de dados em tempo real
- **CSS Modules** - Estilização componentizada e escopada
- **Firebase Hosting** - Deploy e hospedagem

## 📦 Instalação e Configuração

```bash
# Clone o repositório
git clone https://github.com/GustavoOAV/Projeto-VOAR.git

# Acesse o diretório do projeto
cd Projeto-VOAR

# Instale as dependências
npm install

# Configure o Firebase (renomeie o arquivo)
cp .env.example .env

# Inicie o servidor de desenvolvimento
npm start
