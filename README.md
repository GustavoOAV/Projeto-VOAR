# 🎭 Projeto VOAR

> **"Voar É o Que Me Põe de Pé"**  
> Um site oficial para a peça solo de dança e poesia, interpretada por Olívia Araújo, que explora os desafios e vitórias da mulher negra na sociedade contemporânea.

---

## 📖 Descrição

Este repositório contém o código-fonte do site da peça "Voar É o Que Me Põe de Pé".  
O projeto foi desenvolvido para proporcionar uma experiência imersiva ao público, oferecendo informações sobre a peça, a atriz, a equipe criativa e facilitando a interação com os visitantes.

---

## 🚀 Tecnologias Utilizadas

- **Frontend**: React  
- **Bibliotecas**: React Icons, Firebase  
- **Estilização**: CSS  
- **Ferramentas de Desenvolvimento**: Visual Studio Code, Git
